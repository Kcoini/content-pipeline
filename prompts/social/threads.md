# threads 프롬프트

## platform 목적
대화형의 짧은 인사이트를 공유한다. X보다 느슨하고 자연스러운 대화체가
어울리며, 질문으로 마무리해 댓글 반응을 유도할 수 있다.

## 독자 특성
가볍게 스크롤하며 공감할 수 있는 짧은 생각/인사이트를 찾는 독자.

## 글 길이 기준
`preferredLength=short_to_medium`, 최소 30자 ~ 최대 500자.

## 허용 필드
`post_body`(필수), `hashtags`(선택, 2개 내외). `post_title`/`caption`/
`thread_items`/`card_items`는 사용하지 않는다.

## 금지 표현
공통 금지 표현.

## 출력 JSON 형식
```json
{
  "post_body": "대화형 인사이트 (한 문단)",
  "hashtags": ["키워드"],
  "platform_metadata": {}
}
```

## 구조 원칙
- **자연스러운 문장**으로 작성한다 — 목록/구조화보다는 한 사람이
  말하듯 이어지는 문단이 어울린다.
- **질문으로 마무리 가능**하다 ("여러분은 어떠세요?" 같은 형태) — 단
  강요하는 톤이 되지 않도록 한다.

## tone_style 반영 방식
`prompts/tones/*.md` 가이드를 따르되, 격식을 낮추고 대화체로 조정한다.

## 실행 전제
**dry-run 또는 manual copy 전제**다 — 실제 Threads API 게시 연동은
하지 않는다.

## 승인/출처 원칙
- 사람이 승인하기 전에는 게시하지 않는다.
- 출처에 없는 사실을 단정하지 않는다.
- 원문 기사를 그대로 복사하지 않는다.
