# Naver Blog Rewrite Suggestion (참고용)

`SOCIAL_REWRITE_AI_ENABLED=true` 구현 시 naver_blog 플랫폼에 사용할
개선 기준 초안이다. 실제로 이번 단계에서는 읽어서 API에 전달하지 않는다.

## 개선 기준

- 검색형 제목(키워드가 자연스럽게 포함된 제목)으로 개선
- 첫 문단을 더 자연스럽게 개선
- 소제목 구조를 명확히
- 키워드 반복을 줄여 도배로 보이지 않게 함
- 너무 AI스럽거나 딱딱한 문장을 완화
- 태그를 검색 의도에 맞게 정리

## 금지

- 키워드를 억지로 반복하지 않는다.
- 원문 문단을 그대로 복사하지 않는다.
