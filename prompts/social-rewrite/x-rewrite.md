# X Rewrite Suggestion (참고용)

`SOCIAL_REWRITE_AI_ENABLED=true` 구현 시 x 플랫폼에 사용할 개선 기준
초안이다. 실제로 이번 단계에서는 읽어서 API에 전달하지 않는다.

## 개선 기준

- 첫 트윗(hook)을 더 강하게 개선한다.
- thread 순서를 논리적으로 재구성한다.
- 각 item을 더 짧고 명확하게 정리한다(280자 이내).
- 마지막 CTA를 개선한다.
- 해시태그를 과다하지 않게 축소한다.

## 금지

- 클릭을 유도하기 위한 과장 표현을 만들지 않는다.
- "충격", "경악" 등 낚시성 단어를 사용하지 않는다.
