# 금지: 원문 기사 복사

## 금지 내용
출처(source) 원문의 문장을 그대로 옮기거나, 문장 순서만 바꾼 채
사실상 동일한 표현을 그대로 사용하지 않는다.

## 금지 사례
- 출처 문장을 토씨 하나 다르지 않게 그대로 붙여넣기
- 단어 몇 개만 동의어로 치환한 "표절에 가까운" 재구성

## 대신 사용할 것
- 출처의 **정보/사실**만 가져오고, 문장은 반드시 새로 작성한다.
- 필요하다면 직접 인용임을 명시하고 출처를 밝힌다 (전체 문단 단위의
  무단 복제는 어떤 경우에도 금지).
- 타인을 비방하거나 명예를 훼손하는 내용을 포함하지 않는다.
